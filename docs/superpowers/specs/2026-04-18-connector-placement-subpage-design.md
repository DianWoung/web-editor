# 端点定位工作台独立子页面设计

## 背景

当前资产页已经切到模板驱动，但把“端点定位工作台”直接塞进资产编辑主页后，页面出现了两个问题：

1. 信息密度过高，基础信息、模板、定位、3D 参考同时抢占空间
2. 定位工作台需要更大的画布和更稳定的操作节奏，不适合做成主页中的一个紧凑卡片

因此需要把端点定位从资产主页中拆出去，变成一个独立子页面。

## 本次设计结论

### 1. 页面职责拆分

资产页保留：

- 基础信息编辑
- 模型上传
- 连接拓扑模板选择
- 端点定位进度摘要
- 进入定位页入口

独立子页面负责：

- 端点顺序列表
- 主正交视图粗定位
- 辅助正交视图微调
- 3D 参考预览
- 当前端点轻量编辑

结论：资产页负责“管理和摘要”，定位页负责“连续操作”。

### 2. 入口方式

采用“资产页按钮进入”，不在应用模板后自动跳转。

原因：

- 用户可能还需要先修改基础信息
- 用户可能需要先上传模型
- 自动跳转会打断当前资产编辑流程

因此资产页提供明确按钮：

- `进入端点定位`

### 3. 返回方式

定位页顶部提供：

- `返回资产页`

保存后默认停留在定位页，不自动返回。

原因：

- 端点定位通常是连续任务
- 自动返回会打断节奏
- 用户应自己决定何时退出定位页

### 4. 资产页摘要卡

模板区域下方新增“定位摘要卡”，不再直接放完整工作台。

摘要卡至少展示：

- 已完成进度，例如 `2/6 已完成`
- 必需端点未完成数量
- 当前发布风险提示
- `进入端点定位` 按钮

推荐文案形态：

- `2/6 已完成`
- `仍有 2 个必需端点未定位`
- `当前不建议发布`

结论：资产页让用户一眼看出当前状态，而不是在主页完成复杂定位。

## 路由设计

新增子路由：

- `/assets/:assetId/connectors`

职责：

- 加载资产详情和当前 connectors
- 加载模型预览 URL
- 承载独立的端点定位工作台

路由跳转关系：

- 资产页 -> 点击 `进入端点定位` -> 定位页
- 定位页 -> 点击 `返回资产页` -> 回到 `/assets`

不引入新的 modal、drawer 或嵌套路由面板模式。

## 页面结构

### 1. 资产页

模板区域后只保留一个摘要块：

- 模板名称
- 连接点总数
- 已完成数量
- 必需端点剩余数量
- 进入定位按钮

不再在资产页直接渲染：

- 正交视图
- 3D 参考视图
- 逐个端点定位操作区

### 2. 端点定位页

推荐结构：

1. 顶部导航区
   - 返回资产页
   - 当前资产名称
   - 保存连接点

2. 左侧端点进度栏
   - 顺序列表
   - 三段状态：`未开始 / 已粗定位 / 已完成`
   - 当前端点高亮

3. 中间定位区
   - 前视图主画布
   - 右视图微调
   - 顶视图微调

4. 右侧参考与编辑区
   - 3D 只读参考
   - 当前端点名称
   - 当前端点必需
   - 模板锁定语义字段只读展示

## 状态与行为

定位流程保持不变：

1. 按模板顺序选中当前端点
2. 前视图单击粗定位
3. 右视图、顶视图拖拽微调
4. 进入 `已完成`
5. 自动切到下一个端点

状态保持：

- `未开始`
- `已粗定位`
- `已完成`

资产页摘要卡的统计来源：

- `已完成` 数量
- `required === true && status !== 已完成` 的数量

## 数据边界

本次只改页面承载方式，不改现有发布契约。

保持不变：

- `connectors` 仍然是资产端最终保存结构
- `replaceAssetPorts` 仍然是保存入口
- 资产端仍然只允许修改 `name` 和 `required`
- 发布输出和 importer 契约不变

结论：本次是页面拆分，不是数据模型重构。

## 实现建议

### 方案 A：在现有资产页中条件渲染独立布局

优点：

- 改动快

问题：

- 路由语义不清晰
- 页面职责仍然纠缠

### 方案 B：新增独立定位页组件与路由

优点：

- 职责清晰
- 便于后续扩展全屏画布和更复杂的辅助工具
- 资产页可以恢复轻量摘要模式

问题：

- 需要增加路由和页面数据装配

### 推荐方案

采用方案 B：

- 新增独立定位页
- 资产页回到摘要和管理入口
- 工作台完全搬到子页面

## 影响范围

主要涉及：

- `apps/twin-web/src/pages/assets/AssetsPage.tsx`
- 新增 `apps/twin-web/src/pages/assets/AssetConnectorPlacementPage.tsx`
- `apps/twin-web/src/App.tsx` 路由注册
- 现有工作台组件拆分为页面级使用
- 资产页测试改为校验摘要卡和入口按钮
- 定位页新增独立测试

## 非目标

本次不包含：

- 自动跳转到定位页
- 保存后自动返回资产页
- 在 3D 视图中直接编辑端点
- 改变当前模板驱动与复制快照的数据边界
